Please download the raw dataset and mouse GTF annotation files from the following links and place them directly into this directory:

* **Raw Data Download:** 
  * ATAC: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM4156599
  * RNA: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM4156610
* **Mouse GTF Annotation (GENCODE vM23, mm10):** https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_mouse/release_M23/gencode.vM23.annotation.gtf.gz

* **Required Files in this Folder:**
  * `GSM4156599_brain_celltype.txt.gz`
  * `GSM4156599_brain.barcodes.txt.gz`
  * `GSM4156599_brain.counts.txt.gz`
  * `GSM4156599_brain.peaks.bed.gz`
  * `GSM4156610_brain.rna.counts.txt.gz`
  * `gencode.vM23.annotation.gtf.gz`
